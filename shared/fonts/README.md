# Fuentes autoalojadas

El hub y las experiencias no dependen de internet: todas las fuentes viven aquí.

- `bricolage-grotesque.woff2`, `dm-sans.woff2`, `silkscreen-*.woff2`: subconjunto latin de Google Fonts (`../somos-fonts.css`).
- `material-symbols.woff2`: Material Symbols Outlined con **solo** estos íconos (`../somos-icons.css`):

```
add_reaction,approval,arrow_back,auto_awesome,backspace,brush,category,check,close,construction,content_copy,delete,download,draw,flip,flip_to_back,flip_to_front,forest,format_color_fill,format_paint,graphic_eq,grid_off,grid_on,grid_view,highlight_alt,image,ink_eraser,ios_share,landscape,layers,mic,movie,music_note,palette,pause,pets,photo_camera,place,play_arrow,redo,repeat,restart_alt,rotate_90_degrees_cw,rotate_right,route,shuffle,stairs,swap_horiz,swap_vert,text_fields,texture,train,tune,undo,view_week,wallpaper,water,wb_sunny,zoom_in,zoom_out
```

Para agregar un ícono, súmalo a la lista y vuelve a descargar:
`https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0,0&icon_names=<lista ordenada>`
(con un User-Agent de Chrome para recibir woff2).
